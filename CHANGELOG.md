# Changelog

## 1.0.0 - 2026-10-19

First public release.

- Native Android build of GTA V with a Vulkan renderer (app version 2026.10.19).
- Desktop installers for Windows x64, macOS (Intel and Apple silicon), and Linux x64.
  They check your asset files, install the APK, and copy the game data to the phone over USB.
  Interrupted transfers resume where they stopped.
- Source for the Android app, the native runtime, the Vulkan renderer, and the installer.
